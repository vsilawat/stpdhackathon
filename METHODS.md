# Methods

We treated the problem as **recovering the deterministic planning rules of the CAM generator** that
produced the dataset, not as black-box label prediction. The pipeline mirrors a CAM system:
B-Rep feature recognition → process-plan synthesis → analytic in-process-workpiece (IPW) solids →
G-code emission. Learned models are used only where mined rules leave genuine ambiguity, and every
rule below was mined from the training split and validated on a disjoint holdout (every 5th part).

## 1. Feature recognition (`src/machineplan/features.py`)

Pure B-Rep analysis with OpenCascade (cadquery-ocp): cylindrical faces are clustered into holes
(diameter, mouth/bottom z, through/blind via concave-edge floor test), planar recesses into pockets
(corner / center / slot / edge, fillet radius, open sides), and 45° face bands into chamfers.
No mesh learning; the recognizer is deterministic geometry code.

## 2. Operation sequence — Easy track

**Hole process chains.** Mining all 10k plans showed each hole's chain is a function of its geometry.
The recovered decision rules (thresholds are exact round numbers in the data):

- through, d < 12 → spot + twist drill
- through, L/D ≥ 5, d < 32.5 → spot + pilot + gun drill (+ spade if d ≥ 19.3) + enlarge
- through, d < 15 → spot + pilot + enlarge; else indexable insert drill
- blind, d < 10 → spot + drill; d < 12 → + contour mill; d < 15 → hole-mill from solid
- blind, d ≥ 15 → indexable insert (+ enlarge if d ≥ 32)

These rules alone reproduce 82.5% of chains exactly. The residual ambiguity (insert-size grid
membership, soft L/D boundary 4.7–5.3) is handled by a random forest over 10 geometric features:
**96.3% exact-chain accuracy** on holdout. o1/o2 labels are a pure function of the op name.

**Global block template.** Categorising every training op and mining run patterns over `op_index`
revealed the generator's fixed plan skeleton: indexable-insert *blind* chains always lead the plan
(93.7%), then a **twist-drill block** (spot drills first, then drill chains) and a **mill block**
(chamfer area-mills, then pocket mills) in one of two orders — the only genuine binary in the data.
Hole-milling ops glue to the end of whichever block comes first (100% when drilling leads), and
boring follows its hole's mill. Two random forests over 23 part-level features decide the residual
choices: block order (**91.5%** holdout) and hole-mill placement (**81.2%** vs 67.6% base rate).
An oracle with a perfect binary scores 0.105 mean normalised Levenshtein, so the template itself —
not the classifier — carries the structure. Holdout: **mean lev 0.113, set-F1 0.955**.

## 3. IPW solids — Medium track

Each operation's material removal is an **analytic solid** (cylinder + 118° cone tip for twist
drills, flat bottom for insert/bore/mill, prism from the B-Rep outline for pockets/chamfers),
subtracted in sequence from the stock with exact booleans (manifold3d). Mined details that matter:

- spot drill depth below the mouth: `3.0 mm if d ≥ 17.45 else 0.043·d` (99.95% of training rows)
- gun-drill pilot: twist drill to `mouth − 1.5·pilot_d`
- through holes cut to stock bottom; blind cycles end exactly at the detected floor

Holdout: mean IoU 0.991; 62% of ops in the ≥0.999 band.

## 4. Tools — Hard track

Tool type is a pure function of the operation name (spot_drill, twist_drill, gun_drill,
spade_drill, insert_drill, boring_tool, end_mill, chamfer_mill). Tool diameter follows mined
catalog rules: final-cut ops use the hole diameter itself; spot drills are always ⌀12; pocket
end mills are 2× the corner fillet radius; intermediate drills come from per-operation
classifiers over a **discrete tool-size grid** (gun drills: integers + 8.3 mm; spades: 0.5 mm
grid; pilots: 0.1 mm grid) — ≈94% of tools within the 2% diameter tolerance on holdout.

## 5. Toolpaths — Hard track

We reverse-engineered the .ptp grammar from the training programs and re-emit it generatively:
N-numbers step by 2, `T00 M6 / G54` preamble, `G43 Z(top+10)` clearance, canned cycles
`G81/G73/G85 G98 … F250.` with mined parameters:

- retract plane R = mouth + 2 (spot drills: mouth + 3)
- blind cycles: Z = detected hole floor, exactly
- through cycles: Z = exit − (tip_height + 1.5), where tip_height = 0.3004·d (118° twist),
  0.2226·d (spade), 0.0175·d (insert). The 1.5 mm breakthrough clearance is constant across
  the corpus.
- peck cycles (G73): Q = 0.94·tool_d
- gun drilling is a manual block sequence (S716, F125/F250 phases, three G4 dwells) reproduced
  from the mined template; milling ops emit inward-offset contour rings (shapely) at 0.65·d
  stepover.

## 6. Validation discipline

All thresholds and formulas were mined on 80% of parts and reported on the disjoint 20% holdout;
submissions are generated by one deterministic pipeline (`scripts/generate_submission.py`) and
checked with the official `validate_submission.py` (0 format errors on all 4 tracks × 10k parts).
